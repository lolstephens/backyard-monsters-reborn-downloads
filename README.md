## Release status

The launcher and Windows game payload are stable releases. Players can register, update, and launch BYM Reborn through the official desktop launcher.

Independent game endpoint: `https://bymreborn.com/`

Launcher v0.3.0 uses the BYM Reborn package identity across the application, installer, updater, and local data paths. Users on v0.2.0 or newer receive launcher upgrades through the signed in-app updater with automatic data migration.

The Windows installer is not code-signed yet. Windows SmartScreen may show an **Unknown publisher** warning.

Release pages include a SHA-256 checksum so downloaded installers can be verified.
