# Backyard Monsters Reborn Downloads

Official Windows launcher downloads for **Backyard Monsters Reborn**.

## Download

Get the newest installer from the [releases page](https://github.com/lolstephens/backyard-monsters-reborn-downloads/releases).

## Release status

The launcher and Windows game payload are stable releases. Reborn runs against its own HTTPS game server, PostgreSQL account database, and Redis session store on our VPS. Players can register and log in from the game client.

Independent game endpoint: `https://bymreborn.com/`

Launcher v0.2.1 introduces the Golden D.A.V.E. identity, a full-scale game backdrop, and live activity logs. Users on v0.2.0 or newer receive launcher upgrades through the signed in-app updater.

The Windows installer is not code-signed yet. Windows SmartScreen may show an **Unknown publisher** warning.

Release pages include a SHA-256 checksum so downloaded installers can be verified.

The baseline client originates from [Backyard Monsters Refitted](https://github.com/bym-refitted/backyard-monsters-refitted) and retains its GPL-3.0 licensing and upstream attribution.
