# Backyard Monsters Reborn Downloads

Official Windows launcher downloads for **Backyard Monsters Reborn**.

## Download

Get the newest installer from the [latest release](https://github.com/lolstephens/backyard-monsters-reborn-downloads/releases/latest).

## Preview status

The launcher is currently a preview build. The public game package and server endpoint are being prepared separately, so installing the launcher does not yet provide a playable public game build.

The Windows installer is not code-signed yet. Windows SmartScreen may show an **Unknown publisher** warning.

Release pages include a SHA-256 checksum so downloaded installers can be verified.
